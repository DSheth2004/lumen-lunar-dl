# Korokhin et al. (2024) — Shkuratov mixing model + ANN on M³

Reproduction of V. Korokhin, Y. Surkov, U. Mall, V. Kaydash, S. Velichko, Y. Velikodsky and
O. Shalygina (2024), *Applying machine learning to a nonlinear spectral mixing model for mapping
lunar soils composition using CHANDRAYAAN-1 M³ data*, Planetary and Space Science 244, 105870,
doi:10.1016/j.pss.2024.105870.

A plain-language summary is in `../README_Korokhin2024.md`, next to this folder. Technical
documents, in reading order: this file → **`RESULTS.md`** (scorecard, generated by the audit) →
**`PAPER_NOTES.md`** (method, choices D1–D22, findings F1–F14) →
**`SOURCES_AND_LIMITATIONS.md`** (sources, limitations, practical notes).

## Running it

```
python scripts/run_all.py              # everything, ~6-8 h on a 4-core laptop (5-seed ANN)
python scripts/run_all.py --from step05  # everything after the M³ download (no network needed)
python scripts/run_all.py --fast       # skip downloads, ANN training and controls (~40 min)
python scripts/run_all.py --only audit
python scripts/step07_ann.py --warm    # D12 sensitivity: iterations 2-3 fine-tune the previous net
```

The audit is the test suite: it exits non-zero when a gated target misses, which `run_all.py`
reports as a result, not a crash. Tolerances were written into `paper_targets.csv` (by
`scripts/make_targets.py`) before the M³ and ANN results existed.

Stages `step00` and `step00c` rebuild `data/` and `reference/` from sources outside this folder
(RELAB downloads, LSCC spectra, the paper PDF). Both folders are included, and `run_all.py`
skips the two stages when those sources are absent.

Dependencies: numpy, scipy, pandas, matplotlib, **numba** (compiled forward model and
per-sample back-propagation), opencv-python, pypdf, Pillow, PyYAML, torch (a cross-check of the
network's forward pass only). Network access is needed only by `step00` (Fe optical constants)
and `step04` (M³ range requests to PDS and ODE).

Shared code: `korokhin_common.py` (paths, constants, manifest guard, RELAB/LSCC readers),
`shkuratov.py` (Eqs. A1–A16; numpy reference + numba version, agreeing to 7 × 10⁻¹⁵), `nm_fit.py`
(Nelder–Mead with the grain-size corridor), `m3_io.py` (ODE search, LOC probing, range requests).

## Layout

- `data/` — inputs only, sealed by `data/manifest.csv`, verified at the start and end of every stage.
  `relab/`, `lscc/`, `ground_truth/` (sources in its README), `optical_constants/`, `m3/` (scene
  lines, LOC, sites, Apollo 16).
- `reference/` — transcribed tables, digitized figures, images extracted from the paper.
- `products/` — derived arrays (processed cube, ANN maps and weights). Regenerable.
- `tables/`, `figures/` — every number and plot the documents quote.
- `archive/v1_approx_preprocessing/` — a complete run with a simpler, approximate M³
  preprocessing, kept as a sensitivity test; RESULTS.md compares it with the main run.
- `archive/cleanrun_verification/` — log and audit of one `run_all.py` from empty outputs: every
  audit value and table identical to `tables/`, run times aside.

## Headline

46 of 65 gated targets pass; 6 more are near misses (within 1.5 × tolerance); 13 fail
(`RESULTS.md`). The model and the paper's lab tests reproduce; the M³ scene and sites were
identified from the paper's own figure; the ANN matches the paper's ANN values at the highland sites. But three
of its eight maps (OPX, olivine, gray) are set by the training ranges, not by the spectra, and
where the ANN and the optimizer disagree the evidence favours the optimizer. Details in
`PAPER_NOTES.md` F1–F14.
