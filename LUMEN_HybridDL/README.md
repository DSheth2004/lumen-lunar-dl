# LUMEN — LUnar Mineralogy Estimation Network

LUMEN is a hybrid physics + deep-learning method. From a visible / near-infrared reflectance
spectrum (the 71 M³ bands, 0.54–2.50 µm) it estimates:

- the **modal mineralogy** of lunar soil (7 parts: plagioclase, low- and high-Ca pyroxene,
  olivine, ilmenite, agglutinitic glass, other);
- its **bulk chemistry** (FeO, TiO₂, Al₂O₃, CaO, MgO);
- its **maturity** (Is/FeO);

each with calibrated uncertainty.

It is evaluated head-to-head against three published methods, on identical data under
identical protocols:

- Jung et al. 2026 (Hapke + MCMC);
- Korokhin et al. 2024 (Shkuratov model + ANN);
- Fernández-Díaz et al. 2026 (wavelet + autoencoder + random forest).

- **Results:** [`RESULTS.md`](RESULTS.md). It is generated by `scripts/step08_report.py` and
  never edited by hand. It states plainly where LUMEN does *not* win.
- **Pre-registration and design decisions:** [`METHOD_NOTES.md`](METHOD_NOTES.md), committed
  before any model was scored on the real folds.
- **Paper draft:** [`PAPER_DRAFT.md`](PAPER_DRAFT.md).
- **Hand-off and context:** [`HANDOFF.md`](HANDOFF.md).

## Method in one paragraph

1. **Simulator.** A Hapke equivalent-slab simulator generates 400k synthetic soils.
   - It is built from 49 real lunar mineral separates and glasses. None comes from the
     evaluation soils.
   - Space weathering is modelled physically (npFe0 + mpFe0).
   - It randomises end-members, grain size, maturity, calibration tilt and noise.
2. **Network.** A compact 1-D CNN (GroupNorm) reads log-reflectance and continuum-removed
   reflectance. It has a Dirichlet head for composition and β-NLL Gaussian heads for
   chemistry and maturity.
3. **Training.** The CNN is pretrained on the synthetic set, then fine-tuned on the real
   training soils of each fold with:
   - SSA-space mixup (physically mixed spectra with exactly mixed labels);
   - synthetic replay.
4. **Uncertainty.** A 5-member deep ensemble gives raw intervals; conformal calibration
   (normalised CV+-style residuals) gives the reported coverage.
5. **Identifiability gate.** A target is mapped only if its leave-one-soil-out skill over a
   zero-information baseline is significantly positive.

## Data and protocol

- **Data.** 75 RELAB spectra of the 19 LSCC soils (9 mare, 10 highland) × 4 sieve fractions,
  with measured modal mineralogy (56 spectra), bulk chemistry and Is/FeO.
- **LOSO.** Leave one soil out, 19 folds.
- **LOMO.** Leave one mission out, 6 folds. This is the out-of-distribution test: holding out
  A16 removes every feldspathic soil, and holding out A17 every high-Ti soil.
- **Tests.** Paired Wilcoxon over soils with Holm correction, and bootstrap CIs.
- **Inputs.** `data/` holds every input with a SHA-256 manifest. Every stage verifies the
  manifest at its start and end.

## Running

```
pip install -r requirements.txt          # CPU PyTorch is enough
cd scripts
python step00_stage_data.py              # verifies data/ (fresh clone)
python step01_lab_dataset.py             # 75 labelled spectra on the M3 grid (~1 s)
python step02_simulator.py               # self-tests, label model, coverage, 400k synthetic set (~2 min)
python step03_baselines.py               # classic + Fernandez-Diaz baselines, LOSO + LOMO
python step04_lumen.py pretrain          # 5 members on the synthetic set (~1 h on 4 cores)
python step04_lumen.py finetune          # 630 fine-tuning jobs, resumable (~1 h on 4 cores)
python step04_lumen.py collect           # ensembles, metrics
python step05_uncertainty.py             # coverage, skill, identifiability gate
python step06_head_to_head.py            # Jung / Korokhin / Fernandez-Diaz comparisons
python step07_m3_apply.py                # M3: calibration, Apollo 16, Shapley maps, Aristarchus
python step08_report.py                  # writes RESULTS.md
python step09_paper.py                   # writes PAPER_DRAFT.md (asserts every claim in its prose)
```

`scripts/dev_synthetic_only.py` holds the synthetic-only development checks used to fix the
schedule before the pre-registration.

## Layout

| path | content |
|---|---|
| `scripts/lumen_common.py` | paths, manifest guard, I/O, M³ band grid, targets, end-member registry, features |
| `scripts/physics.py` | Hapke core, npFe0 / mpFe0 space weathering, end-member k(λ) library, simulator |
| `scripts/lumen_model.py` | network, losses, SSA-mixup, pretraining / fine-tuning loops, ensembles |
| `scripts/lumen_eval.py` | per-soil errors, skill, bootstrap, Wilcoxon + Holm, mean-of-others |
| `tables/` | every number reported, as CSV (the table view of every figure) |
| `figures/` | figures for the paper |
| `products/` | regenerable arrays: synthetic set, checkpoints, maps (not in git) |
