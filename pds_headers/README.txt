M3 header and label files for the four Chandrayaan-1 M3 images used in the two paper
reproductions. Downloaded from the NASA PDS Imaging Node, 2026-09-23.

Each image has four small files:
  *_V01_RFL.HDR   ENVI header of the Level 2 reflectance image (85 band wavelengths, size)
  *_V01_L2.LBL    PDS label of the Level 2 reflectance image
  *_V03_LOC.HDR   ENVI header of the Level 1B location (latitude/longitude) file
  *_V03_L1B.LBL   PDS label of the Level 1B products

These describe the images. The image data itself is in the .IMG files, which are 1.7-2.9 GB
each and are not included here; the download links are below.

Paper1_Jung2026/
  M3G20090208T160125/   site b of the paper's Figure 5, 21.37 N, 320.54 E
  M3G20090208T233940/   site c of the paper's Figure 5, 31.76 N, 315.82 E

Paper3_Korokhin2024/
  M3G20090728T214215_Shapley/    main image, Shapley crater area
  M3G20090607T110414_Apollo16/   Apollo 16 site, used for the paper's Eq. 2 calibration
